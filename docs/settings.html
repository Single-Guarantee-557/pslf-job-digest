Connect or change token
  1. Open GitHub → New fine-grained token.
  2. Name it “Job digest settings” and pick an expiration (up to a year).
  3. Under Repository access, choose Only select repositories and pick your job digest repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write and Actions to Read and write.
  5. Click Generate token, copy it, and paste it below.

The token is stored only in this browser. It is never saved to your repository. Anyone using this browser could edit your settings, so use “Forget token” on shared computers.
